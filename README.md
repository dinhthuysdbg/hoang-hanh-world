# Hoàng Hạnh's World ❤️

Website kỷ niệm riêng dành tặng Hoàng Hạnh — một góc nhỏ lưu giữ câu chuyện tình yêu, những khoảnh khắc đáng nhớ và lời nhắn gửi dành cho hai người.

## Công nghệ
- React + TypeScript
- Vite
- CSS responsive, mobile-first

## Chạy dự án
```bash
npm install
npm run dev
```

## Quy chuẩn thiết kế
Đọc `DESIGN_GUIDELINES.md` và `AGENTS.md` trước khi phát triển. Ưu tiên trải nghiệm tinh tế, responsive, tiếng Việt chuẩn và giữ nhất quán Design System.
